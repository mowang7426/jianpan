# 智能流畅模式 v1（源码测试版）

设置首页新增“智能流畅模式”，默认开启，可随时关闭。

## 行为
- 正常：保持已有主题、光效、候选词动画。
- 连续卡顿：关闭背景扩散/光晕，最多2组光效，缩短持续时间，候选词停止装饰动画但仍随文字更新。
- 继续卡顿：最多1组短时单键光效，暂时绕过候选词渐变及原生文字位图扫描。
- 稳定：连续8个稳定采样窗口后恢复一级，不在一次偶发卡顿后立刻来回切换。
- 闲置：停止打字1.5秒后停测；超过5秒未打字或键盘隐藏/进程进入后台时重置。已保存的主题颜色不变。

监测20Hz显示回调的实际间隔，85ms以上计为延迟；每个约1秒窗口至少2次延迟且占比20%以上才算不稳定，连续2个不稳定窗口降一级。它是主线程调度压力的近似值，不是精确输入延迟测量，不能保证捕捉到所有卡顿。

## 限制
按键盘进程/当前输入会话适应，不保存App黑名单。共享输入法进程短时间切换App且未触发键盘隐藏时，可能短暂沿用当前级别。不能修复App、输入法算法或系统自身的卡顿。不记录文字，不联网，不在按键时读写磁盘。监测仅在插件识别到键盘触摸路径时启动，硬件键盘等未覆盖。
